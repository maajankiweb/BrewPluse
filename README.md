# BrewPluse – Run your cafe. Not your software.

> **BrewPluse** is a modern cafe management, POS counter billing, QR table ordering, and kitchen display (KDS) operating system landing page clone of [brewpluse.com](https://brewpluse.com/), built as a pure, standalone **Next.js** application.

---

## ☕ What is Included

1. **Exact 8 Home Page Sections**:
   - **Section 1 (Hero & Tablet Simulator)**: Headline, subhead, CTA buttons, and interactive tablet POS simulator (sidebar, live orders table, sales trajectory chart, floating mobile phone storefront, and fee mode badges).
   - **Section 2 (Trust Ribbon)**: Trusted by modern cafes, simple setup, QR ordering, secure payments, delivery ready, 24/7 support.
   - **Section 3 (Love from Cafes)**: 4.9/5 stars badge and verified cafe owner reviews.
   - **Section 4 (System Simplification)**: Side-by-side comparison (5 apps chaos vs. 1 synchronized heartbeat).
   - **Section 5 (Transparent Pricing Architecture)**: Interactive order volume slider with savings calculator and fee-payer switch (Customer-Faced vs. Cafe-Faced mode).
   - **Section 6 (Features Grid)**: 8 core operations cards (Digital Orders, Smart POS Billing, Menu Management, Inventory 86, Staff Ordering, Analytics, Loyalty, Hardware Agnostic).
   - **Section 7 (Why BrewPluse & FAQ)**: Side-by-side layout with the complete comparison table (BrewPluse vs Traditional POS vs Multiple Apps) and the 6 expandable FAQ accordion items.
   - **Section 8 (Bottom CTA Banner)**: High-impact banner featuring your illuminated **BrewPluse** storefront illustration.

2. **Navbar & Footer**:
   - Sticky blur backdrop **Navbar** with mega-dropdowns for Modules, Solutions, and Resources, cleanly linked to internal sections.
   - Full 4-column **Footer** matching `brewpluse.com` (brand details, solutions, resources, legal, and operational status).

3. **Pure Next.js Architecture**:
   - Single, clean full-stack project (no redundant separate `server` folder).
   - Runs with standard `npm run dev`.

---

## 🚀 Quick Start

```bash
# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.
